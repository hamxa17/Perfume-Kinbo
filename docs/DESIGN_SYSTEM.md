# Design System & Styling

## Aesthetic & Vibe
* **Mood:** Minimalist, sophisticated, luxurious, editorial.
* **Palette:** Deep charcoals, soft creams, warm neutrals, and subtle gold/bronze accents.

## Tools
* **Icons:** `lucide-react` (for filters, search, shopping bag, arrows).
* **Styling:** Tailwind CSS (or CSS Modules if preferred).
